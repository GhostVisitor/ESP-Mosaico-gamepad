## 设计要点速查

### 1. 最小系统

- **CH552T（TSSOP-20）** 内置 USB 与振荡器，**不需要外部晶振**。
- `VCC` 就近放 **0.1 µF** 去耦电容（手册要求）。
- `V33` 的去耦见下表（按供电电压选）：
  - 供电 **< 3.6 V** → `V33` 与 `VCC` **短接**
  - 供电 **> 3.6 V** → `V33` 只挂 **0.1 µF** 到 GND，**不要**接 VCC
- `RST` 内置下拉；其余 GPIO 默认带上拉 —— **按键直接接 GND 即可，无需外部上拉。**

### 2. 按键接法

12 个轻触开关，每个一端接 MCU 引脚、另一端**统一接 GND**：

```
P1.0 ~ P1.7  → SW1 ~ SW8
P3.2 ~ P3.5  → SW9 ~ SW12
```

> 布局建议按街机面板习惯：左侧十字（SW1~SW4）、右侧 ABXY（SW5~SW8）、
> 下方 SELECT/START（SW9/SW10）、肩键 LT/RT（SW11/SW12）。

### 3. USB

- `P3.6 = D+`、`P3.7 = D−`，直接连 USB 座（无需 22 Ω 串阻，CH552 内置）。
- 建议留一个 **10 kΩ + 跳线/按键** 把 `D+` 上拉到 VCC，用于**进入 bootloader 烧录**。

### 4. 串口

- `P3.1 = TXD` → 主控 `RX`，**务必共地**。
- `P3.0 = RXD` 已预留（本固件只发不收，可引排针备用）。

### 5. ⚠️ 布线与引脚注意

- **`P1.2` / `P1.3` 同时是晶振脚 `XI` / `XO`**（TSSOP-20 的 17/16 脚）。
  固件已关闭外部晶振把它们当普通 IO 用，但**布线上别在这两个脚挂晶振或长线**。
- `P3.2` 同时是 `INT0`、`P3.3` 是 `INT1`、`P3.4/P3.5` 是 `T0/T1`
  —— 当普通按键输入使用，固件里没有打开对应外设。
- `P3.6/P3.7` 被 USB 占用，**不可复用**。
